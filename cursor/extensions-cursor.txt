# WHAT: Extensions installed into Cursor but not Visual Studio Code. Each is
#       Anysphere's substitute for a Microsoft extension that Cursor's gallery
#       (marketplace.cursorapi.com) does not serve: Pylance, the C++ tools,
#       and the ms-vscode-remote.* family.
# WHY : The gallery mirrors most of Microsoft's Marketplace but not its
#       licence-restricted extensions. The gallery query in
#       ../vscode/README.md § Extensions shows whether an id needs a
#       substitute.
# HOW : One id per line; `#` starts a comment. The shared ids are in
#       ../vscode/extensions.txt.
# NOTE: The file ../vscode/extensions-vscode.txt lists the VS Code extension
#       each entry here replaces. Change one file, check the other.
# ==============================================================================

# Python type checking.        Substitutes for: ms-python.vscode-pylance
anysphere.cursorpyright

# C and C++ IntelliSense.      Substitutes for: ms-vscode.cpptools,
#                                               ms-vscode.cpp-devtools
# NOTE: Cursor bundles this one and refuses to uninstall it. It stays listed so
#       a fresh machine declares it; install.sh skips ids already installed.
anysphere.cpptools

# Remote development.          Substitutes for: ms-vscode-remote.remote-ssh,
#                                               ms-vscode-remote.remote-ssh-edit,
#                                               ms-vscode.remote-explorer
anysphere.remote-ssh

# Dev containers.              Substitutes for: ms-vscode-remote.remote-containers
anysphere.remote-containers
